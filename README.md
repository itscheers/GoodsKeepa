# 📦 GoodsKeepa

**GoodsKeepa** — це десктопний застосунок для електронного обліку товарів на складі, реалізований на Java з використанням JavaFX для графічного інтерфейсу та SQLite для збереження даних.

## 🛠️ Технології

- Java 21
- JavaFX
- Maven
- SQLite
- JUnit (для тестування)

## 💡 Основні можливості

- Додавання, редагування та видалення товарів
- Категоризація продукції
- Облік постачальників
- Зручний графічний інтерфейс
- Зберігання даних у локальній базі SQLite
- Покриття коду юніт-тестами

## 🧩 Архітектура

Проєкт побудований за шаблоном MVC:

- **Model** — робота з базою даних (DAO)
- **View** — FXML-інтерфейси (JavaFX)
- **Controller** — логіка взаємодії з користувачем

## 🚀 Запуск

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/itscheers/GoodsKeepa
   ```

2. Відкрийте проєкт у IntelliJ IDEA

3. Запустіть застосунок з файлу `pom.xml` за допомогою:
      ```bash
      mvn javafx:run
      ```

## 🧪 Тестування

Для запуску юніт-тестів:
```bash
mvn test
```
